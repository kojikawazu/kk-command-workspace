# scripts

ワークスペース運用スクリプト。

## gen-index.sh — 索引の自動生成

`readme.md` の索引ブロックをディレクトリツリーから自動生成します。

```bash
bash scripts/gen-index.sh
```

### 仕様

- トップレベルディレクトリを走査し、配下の `*.md` を再帰収集して索引を生成します。
- リンクラベルは各ファイルの先頭 H1（`# ...`）を使用。H1 が無ければファイル名にフォールバックします。
- `readme.md` 内の `<!-- AUTO-INDEX:START -->` 〜 `<!-- AUTO-INDEX:END -->` の間**だけ**を差し替えます。マーカー外の手書き部分（タイトル・前書き）は保持されます。
- **冪等**です（再実行しても差分は出ません）。
- 除外対象: `.git` `.claude` `scripts` `private` `node_modules`

### 運用

ドキュメントを追加・削除・移動した際は本スクリプトを実行して索引を再生成してください。
`readme.md` の索引は手で編集せず、常にスクリプトで生成します（前書き部分は手編集可）。
